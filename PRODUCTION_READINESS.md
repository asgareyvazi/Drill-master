Content reads now decide on the opened object: POSIX opens component-by-component relative to a descriptor for the work root with `O_NOFOLLOW` on every component and `O_NONBLOCK` on the last, then requires `S_ISREG` on the *handle*, so a swapped-in link fails the open instead of yielding its target and a planted FIFO is refused rather than awaited; Windows has neither descriptor-relative open nor a meaningful `O_NOFOLLOW`, so the verdict is bound to the handle through `GetFileType`/`GetFileInformationByHandle`/`GetFinalPathNameByHandleW` (final path under the root's own final path, same volume, the reparse attribute bit refused even when the target is inside the root, and the reached path compared against the named path so an in-root junction cannot substitute another file), with unavailable or unreadable metadata failing closed; `CreateFileW` resolves links before the handle exists, so that platform narrows the window rather than eliminating it, and no host that cannot prove confinement is allowed to fall back to an unanchored read. `run_lifecycle` records the work root's identity once and every anchored open re-validates it, so replacing the root cannot silently move the boundary. `LOG_TAIL_BYTES` became a non-bypassable ceiling — a smaller `byte_limit` is honoured, a larger one raises `ValueError` before any open — and the single permitted probe byte is spent on the *front* boundary so a window that begins at a line boundary keeps its first line (`dropped_partial_first_line=false`) instead of discarding a whole line, while growth is detected by re-seeking the same handle (`grew_during_read`).
