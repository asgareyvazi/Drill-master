## Canonicality and regression risk

- Corrections reuse existing numerical, inventory, scope and financial boundaries; no new dependency, generic framework or speculative financial model.
- Changes intentionally make invalid supplied data fail rather than be silently coerced. Callers relying on malformed/bool stock inputs must correct their data; prior rows survive failure.
- Search exceptions now reach callers. The actual UI caller and the public retrieval wrapper were updated and tested. Prototype methods without production wiring were retained, not deleted.
- Scope coverage semantics changed intentionally: displayed persisted quality must not improve merely because a proposal exists.
- Canonical conversions now catch OverflowError as well as TypeError/ValueError. Required invalid input remains error, optional missing remains None.
- Current function bodies and identified consumers were reread after repairs. This limited re-review does not approve the other 2191 inventory occurrences.
